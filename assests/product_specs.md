# Product Specification Rules

## Discount Code Feature
- The valid discount code is `SAVE15`.
- `SAVE15` applies a **15% discount** to the Current Subtotal.
- The maximum discount amount allowed per order is $50.
- Any other code should display "Invalid discount code."

## Shipping Costs
- **Standard shipping is free.**
- **Express shipping costs $10.00.**

## Payment Logic
- The "Pay Now" button should only be enabled when all required form fields (Name, Email) are filled.
- Upon successful payment, the message "Payment Successful!" should be displayed.
